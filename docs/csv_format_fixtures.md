# CSV 格式测试样例

本样例依据 `决赛/样本1` 中的字段模板构造，只用于测试 CSV 读写。
所有数值均为人工占位值，不含仿真机理、策略优劣、收益标签或可用训练结果。
两个目录是两个格式测试用例，不是策略的仿真结果。目前不构造空值用例。

## 文件与字段

- 输出位置：`outputs/csv_format_fixtures/`。
- 保留模板第一行的字段名称、大小写、顺序；第二行类型和第三行说明不写入 CSV。
- 保留模板文件名及分段编号，仅将扩展名改为 `.csv`。
- 每个包含时间字段的文件构造 200 条记录，每条对应一个测试时间刻；无时间字段的文件构造一条记录。
- 分段时间为 `文件序号 × 200 + 文件内行序号`，仅用于测试分段读取，不代表真实采样间隔。
- 所有标识整数均使用占位值，未验证跨表关系；字符串含逗号和双引号，用于检验 CSV 转义。
- 不补齐模板中不存在的分段，因此不同表覆盖的时间范围可能不同。

## 两组用例

| 目录 | 构造内容 | 验证目标 |
|---|---|---|
| basic | 完整数值，布尔字段交替 True/False | 字段、类型和转义读写 |
| delayed_flags | 所有布尔字段在序号 0、1、2 文件内为 False，序号 3 起为 True | 验证前期全 False 仍可读取，不应直接删除 |

延迟布尔值用例是统一的解析测试规则，不表示字段之间存在业务关系。

## 本地序列化约定

编码为 UTF-8 BOM，分隔符为逗号，换行为 CRLF，布尔文本为 `True`/`False`。样例内所有单元格均有值，样例验证拒绝空值。
这些是本地测试约定，未从真实赛方 CSV 验证。字符串枚举、时间单位和数值范围也尚未验证。
赛方实际编码或布尔写法不同时，需要调整读取配置；本次通过不等于赛方电脑集成通过。

读取器按列名取值，默认允许额外列，拒绝缺列、重复表头、错列数以及不符合声明类型的文本。
人工来源标记和表结构放在 `manifest.json` 中，不向 CSV 添加字段或说明行。

## 运行

生成需要 Python 和 openpyxl（只读取 Excel 模板）。验证已生成 CSV 只使用 Python 标准库。

```powershell
python scripts/make_csv_format_fixtures.py --templates 决赛/样本1 --output outputs/csv_format_fixtures
python scripts/make_csv_format_fixtures.py --output outputs/csv_format_fixtures --validate-only
```

生成命令拒绝覆盖非空输出目录。重新生成时指定新的输出目录。
生成完成会重新读取所有 CSV，逐单元格核对类型与值，并输出 `validation_report.json`。
验证命令不修改现有文件。该命令用于验证人工用例，不能用作真实仿真数据的业务校验器。
